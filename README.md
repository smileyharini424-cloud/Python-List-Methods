# Python List Methods

## Explanation

Python lists provide several built-in methods for adding, removing, searching, and rearranging elements.

## Problem Statement

Write a Python program that demonstrates commonly used list methods on a list of numbers.

## Features

* Adds an element using `append()`
* Inserts an element using `insert()`
* Removes an element using `remove()`
* Removes an element using `pop()`
* Sorts elements using `sort()`
* Reverses elements using `reverse()`

## How It Works

The program creates a list and applies different list methods one by one.

### Methods Used

* `append()` – adds an element at the end
* `insert()` – adds an element at a specific position
* `remove()` – removes a specified element
* `pop()` – removes an element using its index
* `sort()` – arranges elements in ascending order
* `reverse()` – reverses the order of elements

## Technologies Used

* Python 3

## Program Flow

1. Create a list.
2. Add an element using `append()`.
3. Insert an element using `insert()`.
4. Remove an element using `remove()`.
5. Remove an element using `pop()`.
6. Sort the list.
7. Reverse the list.
8. Display the results.

## Sample Output

